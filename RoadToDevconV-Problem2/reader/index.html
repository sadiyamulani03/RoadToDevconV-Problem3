Deccan Birders — Independent Reader

Standalone reader with its own entrypoint. It reaches Swarm directly, downloads through the same /bytes family used when storing, parses the portable record, validates format/version, and renders — without importing any authoring-side code. The only shared module is ../shared/format.js (standalone schema).

The authoring app lives separately at ../writer/index.html. This page shares no components, storage helpers, or rendering code with it.
